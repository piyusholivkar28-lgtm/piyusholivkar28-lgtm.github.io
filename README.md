# Piyush Olivkar — Academic Website

A static, GitHub Pages-ready academic website.

## Files
- `index.html` — site content and structure
- `style.css` — responsive visual design
- `script.js` — mobile menu, reveal animation and equation rotation
- `assets/piyush-olivkar.jpg` — profile photograph
- `assets/Piyush_Olivkar_CV.pdf` — downloadable CV

## Publish on GitHub Pages
1. Create a new public repository, for example `piyusholivkar28-lgtm.github.io`.
2. Upload the contents of this folder to the repository root.
3. In GitHub: Settings → Pages.
4. Choose `Deploy from a branch`.
5. Select `main` and `/ (root)`.
6. The site will be published at:
   `https://piyusholivkar28-lgtm.github.io/`

If you instead use a normal repository name, GitHub Pages will publish under:
`https://piyusholivkar28-lgtm.github.io/<repository-name>/`

## Visitor statistics / map
The current site deliberately does not fake visitor numbers. After deployment, connect a provider such as
GoatCounter, Plausible, Cloudflare Web Analytics or a visitor-map service and replace the placeholder
inside the `#visitors` section.

## Updating content
The site is intentionally a single-page academic profile so it remains easy to maintain. As the publication
record grows, add a dedicated Publications section rather than creating an empty page now.

## Important
The gallery graphics are schematic visual motifs, not claimed research results. Replace them over time with
validated figures from your own work.
